Bates numbering on Mac without a subscription

Bates numbering is one of the last reasons small firms keep a Windows machine around. On a Mac there are options, but most of them are either a subscription, a general-purpose PDF editor where Bates numbering is one feature among a hundred, or a tool that handles one file at a time. Here is what they cost, and where BatesStamp fits.

What you actually get for the difference

The price is the easy part. The real difference is what happens when a production runs across more than one file.

  • Continuous numbering across the whole batch — one number per page, from the first page of the first file to the last page of the last, not a counter that restarts with every document.
  • A register of every production — a CSV written beside the output listing each file, the range assigned, the page count and a SHA-256 hash of every file produced, so a production can be verified without opening a single PDF.
  • Overlap protection — the app remembers the last number used for each prefix and warns you before a run reuses numbers you have already served.
  • Real text, not images — Cmd-F finds any Bates number in Preview, Acrobat, or a review platform.
  • Originals untouched — stamped copies are written to a folder you choose; removing a stamp restores the file byte-for-byte.

Why offline matters here

BatesStamp is sandboxed and ships without the network entitlement, which means macOS itself prevents it from opening a network connection. For privileged material that is a property you can inspect rather than a promise in a privacy policy. There is no account, no login, no licence server and no analytics.

What it does not do

BatesStamp does only Bates numbering. It does not edit, redact, OCR or sign PDFs — if you need those, you need a full PDF editor as well. It requires macOS 14 or later, and there is no iPad version.

Available on the Mac App Store in the United States, the United Kingdom, Canada, Australia and other regions. Not currently on sale in the European Union.
