What is a Bates number?

A Bates number is a unique identifier printed on every page of a document production, so that any single page can be referred to exactly, by anyone, for as long as the matter lasts.

If two lawyers on opposite sides of a case need to discuss one page out of forty thousand, they need a way to name that page that cannot be misread. Page numbers inside the original files do not work: three different documents will each have a page 7. Bates numbering solves this by giving every page in the entire production one number that appears nowhere else.

The name comes from the Bates Automatic Numbering Machine, a hand stamp with rotating wheels patented in the 1890s. It advanced by one each time it struck a page. The machine is long gone; the practice and the name stayed.

What a Bates number looks like

Almost every Bates number has two parts: a prefix that identifies who produced the documents, and a sequential number padded with leading zeros.

Example Reading
ACME000001 First page produced by Acme, six digits
SMITH-00042 Forty-second page, prefix separated by a hyphen
DEF0001234 Defendant's production, page 1234

The leading zeros are not decoration. They keep every identifier the same width, which means the numbers sort correctly in a file browser or a spreadsheet. Without padding, ACME2 sorts after ACME10, and a production that sorts wrong is a production that is hard to work with.

How many digits you choose sets a ceiling. Six digits gives you 999,999 pages, which is comfortable for almost anything. Four digits gives you 9,999, and the day you exceed it you have a problem with no clean solution, because the numbers you already produced cannot be changed.

Where the number is placed

Convention puts the Bates number in the bottom-right corner of the page, outside the body text. The corner matters less than the consistency: it must be in the same position on every page, and it must not cover anything that was already there.

Why the number must be unique across the whole production

This is the part that causes the most trouble in practice.

A production is usually not one file. It is a folder of files — thirty PDFs, say, adding up to four hundred pages. The Bates sequence must run straight through all of them: the first page of the first file is ACME000001, and the last page of the last file is ACME000400. It does not restart at 1 when a new file begins.

If it does restart, you now have thirty pages numbered ACME000001, and the identifier no longer identifies anything. Citing "ACME000001" in a deposition becomes meaningless. This is the single most common failure when people number documents with a tool that only handles one file at a time.

The rule in one line: one number, one page, for the entire matter — not for the file.

What it is not

Not page numbering

Page numbering tells you where you are inside a document. Bates numbering tells you which page of the production you are holding. A brief can have both, and they will not match.

Not redaction

Numbering and redaction are separate steps, and the order matters: you redact first, then number, so the numbers appear on the version that actually goes out.

Not a confidentiality designation

Stamps such as CONFIDENTIAL or ATTORNEYS' EYES ONLY are often applied alongside Bates numbers and are sometimes handled by the same tool, but they are a different thing with different rules, usually set by a protective order.

Keeping a record of what you produced

Producing documents is not only about stamping them. Months later you may need to answer a precise question: which pages went out in the March production, and were they the same files you have on disk now?

A production register answers that. At minimum it records, for each production: the date, the prefix, the range of numbers used, the file names, and the page count of each file. Some tools also record a hash of every output file — a short fingerprint that changes if even one byte of the file changes. If a dispute arises about whether a document was altered after production, that fingerprint is the difference between demonstrating something and asserting it.

Common mistakes

  • Restarting the sequence on each file. Destroys uniqueness. The most frequent and most damaging error.
  • Reusing a range across two productions. Always continue from the last number used, never start over.
  • Too few digits. Pick the ceiling before you start, not when you hit it.
  • Numbering the originals instead of copies. Stamp copies and keep the originals untouched, so a mistake costs you a re-run rather than the source material.
  • Stamping over content. Check a few pages of every production, especially documents with unusual margins or landscape pages.
  • No record of what was produced. Reconstructing it later from memory is unreliable and sometimes impossible.

Doing it on a Mac

The practice is the same on any platform, but the tools are not. macOS has no built-in Bates numbering, and many of the free options handle one file at a time — which, as above, is exactly the case where numbering goes wrong.
